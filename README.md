# Work Hours Calculator 💰

A simple web application to calculate how many hours you need to work to buy something, with support for Indian Rupees (₹).

## Features
- Calculate work hours needed for any purchase
- Support for flexible work schedules (1-7 days per week)
- Leave without pay calculations
- Tax deduction considerations
- Responsive design for all devices
- Indian Rupee (₹) currency support

## How to Use
1. Enter your monthly salary in rupees
2. Specify your work schedule (days per week, hours per day)
3. Add unpaid leave days if applicable
4. Enter the item name and price you want to buy
5. Optionally add your tax rate for accurate calculations
6. Click "Calculate Work Hours" to see results

## Deployment Options

### Option 1: GitHub Pages (Free)
1. Create a new repository on GitHub
2. Upload all files (index.html, styles.css, script.js)
3. Go to repository Settings → Pages
4. Select "Deploy from a branch" → main branch
5. Your site will be available at: `https://yourusername.github.io/repository-name`

### Option 2: Netlify (Free)
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop this folder to Netlify
3. Your site will be deployed instantly with a custom URL

### Option 3: Vercel (Free)
1. Go to [vercel.com](https://vercel.com)
2. Import your GitHub repository or upload files
3. Deploy with one click

### Option 4: Local Development
1. Simply open `index.html` in any web browser
2. No server required - works offline
